# Troubleshooting notes

### Python 2 / tutorial mismatch
Older Empire tutorials assumed a legacy Python 2 environment. I moved to a newer setup to continue the exercise, and learned to check tool version/documentation compatibility early.

### File download vs. execution
The documented transfer completed successfully, and the file was present in the Windows user's directory. A later execution issue required additional investigation. Screenshots supplied for this portfolio do not confirm the command's final outcome, so the README does not claim successful agent execution on this VM.

### Lessons for reproducibility
Capture complete version information, endpoint timestamps, VM snapshots, host-only networking configuration, and process logs for any future demonstration.
